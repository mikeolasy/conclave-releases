# Conclave

Downloads for **Conclave**, a Windows desktop app by [Vorelyn Studios](https://www.vorelynstudios.com/our-projects/conclave).

Bring Conclave a question or a request for ideas, and a panel of seven AI agents researches it on the live web, argues it out and votes. A chair then writes a report with sources that you can export as PDF, Word, slides or Markdown.

Conclave is a working prototype.

## Download

**[Download Conclave for Windows](https://github.com/mikeolasy/conclave-releases/releases/latest/download/Conclave-Setup.exe)** (Windows 10 or 11, 64-bit)

## Before you install

- **Windows may warn you.** The installer isn't code-signed yet, so Windows SmartScreen may say "Windows protected your PC". Click **More info → Run anyway**.
- **You need your own API key** from Anthropic, OpenAI or OpenRouter. Conclave uses the models of the service you connect, and you pay that service for what you use. Each session has a spending cap, $10 by default.
- **Your keys stay on your computer.** They're encrypted with Windows' own protection and only used to call the service they belong to.

## Install

1. Run **Conclave-Setup.exe**.
2. Choose **Only for me** (no administrator rights needed), keep the suggested folder and click **Install**.
3. Click **Finish**. Conclave opens and asks for an API key.

To update, run a newer installer and choose **Update or repair**. Your keys, history and settings stay. To uninstall, go to **Settings → Apps**.
